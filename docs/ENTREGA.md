# Conferência da entrega

O Canvas solicita uma **URL de site**. O ZIP serve como cópia do código e da documentação.

## Implementação

- React com Vite.
- Menu para Sobre Mim, Projetos, Experiências e Contato.
- Apresentação em português e inglês.
- Timeline baseada nos dados dos projetos, em ordem cronológica.
- Nome, descrição, tecnologias, GitHub e imagem real em cada projeto.
- Experiências acadêmicas com instituição, atividade, período e descrição.
- Contatos clicáveis: e-mail, LinkedIn e GitHub.
- Formulário com validação e integração de envio por e-mail.
- Layout responsivo, animações leves e opção de movimento reduzido.
- README adaptado ao template da disciplina.
- Wireframes de desktop e celular preparados em SVG editável.

## Situação das etapas externas

| Etapa | O que falta |
| --- | --- |
| GitHub | Repositório criado em https://github.com/thiagoguerra-199/portfolio-profissional. Conferir o conteúdo enviado e a URL da Vercel após a publicação. |

| Formulário | Ativar o destinatário no FormSubmit, caso solicitado no primeiro uso, e confirmar o recebimento de uma mensagem real. |
| Vercel | Publicar pelo próprio autor, conforme combinado, e inserir a URL pública no README. |

## Antes de enviar ao professor

1. Conclua as quatro etapas externas acima.
2. Abra o site em uma janela anônima e confira os links e as imagens.
3. Teste o menu no celular e os dois idiomas.
4. Confira a chegada da mensagem do formulário.
5. Envie a URL pública da Vercel no Canvas.

## Arquivo ZIP

Inclui código-fonte, dependências declaradas, imagens, configurações, wireframes e documentação. Não inclui `node_modules`, histórico Git, arquivos temporários, dados de autenticação ou cópias dos códigos dos outros projetos.
